# 头像库来源与署名（主包 · 可随产品分发）

本目录 67 款头像（256×256 WebP）由用户自行 AI 生成设定图并切图制作，权利归用户自有，可随蜂群各发行物（含收费版）分发。

主包目录收录这 67 款自有素材。没有专属头像的模型系列使用默认徽像，也可在头像库中添加自己的图片。
